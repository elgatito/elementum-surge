Elementum is a community-driven open-source project. Pull requests are welcome in every repository:

| Repository | What it is |
|------------|------------|
| [plugin.video.elementum](https://github.com/elgatito/plugin.video.elementum) | The Kodi add-on (Python): menus, settings, translations. |
| [elementum](https://github.com/elgatito/elementum) | The daemon (Go): torrent streaming, library, tracking services. |
| [script.elementum.burst](https://github.com/elgatito/script.elementum.burst) | Burst search add-on and its providers, see [How to add a provider]({{% relref "/burst/create.md" %}}). |
| [context.elementum](https://github.com/elgatito/context.elementum) | Context menu add-on. |
| [elementum-surge](https://github.com/elgatito/elementum-surge) | This website. |

## Translations

Add-on texts are in `resources/language/resource.language.<code>/strings.po` of each add-on. Fix or add a language and open a pull request.

## Documentation

Every page of this site has an edit button at the top. It opens the page source on GitHub, where you can propose a change.
Changes are published with the next site release after they are merged.

## Bugs and ideas

[Report bugs]({{% relref "/help/report-issue.md" %}}) and [suggest features]({{% relref "/help/request-feature.md" %}}) on GitHub.
You can also [support the development]({{% relref "/donate/_index.md" %}}).
