## Where to post

Open an issue in the repository of the part you'd like to improve:

- Elementum add-on: [plugin.video.elementum](https://github.com/elgatito/plugin.video.elementum/issues)
- Burst: [script.elementum.burst](https://github.com/elgatito/script.elementum.burst/issues)
- Context add-on: [context.elementum](https://github.com/elgatito/context.elementum/issues)
- Elementum daemon (the binary part of the add-on): [elementum](https://github.com/elgatito/elementum/issues)
- This website: [elementum-surge](https://github.com/elgatito/elementum-surge/issues)

## Writing a request

Describe what you'd like to have and how you see it working. The more details, the easier it is to understand your idea.
