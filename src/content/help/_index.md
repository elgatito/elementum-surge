Something doesn't work? Go through these steps:

1. Check the [FAQ]({{% relref "faq.md" %}}), most common problems are answered there.
2. Make sure you run the latest version, see [release notes]({{% relref "/release-notes/_index.md" %}}) and [Updating]({{% relref "/getting-started/updating.md" %}}).
3. Reproduce the problem and [collect a log file]({{% relref "log.md" %}}).
4. [Report the issue]({{% relref "report-issue.md" %}}) on GitHub with the log attached.
