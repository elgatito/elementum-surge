## Requirements

- [Kodi](https://kodi.tv/download/) 19 (Matrix) or newer is recommended. Elementum itself still starts on Kodi 16+, but Burst needs Kodi 19+.
- One of the supported platforms:

| Platform | Minimum OS |
|----------|------------|
| Windows x64 / x86 | Windows 10 / Windows Server 2016 |
| Linux x64 / x86, arm64, armv7 | glibc 2.28 (Debian 10, Ubuntu 20.04, RHEL 8) |
| Linux armv6 (Raspberry Pi 1 / Zero) | glibc 2.10 |
| Android arm / arm64 / x86 / x64 | Android 5.0 |
| macOS Intel / Apple Silicon | macOS 13 Ventura |

On other systems you can run Elementum in [client-server mode]({{% relref "/configuration/command-line.md#client-server-mode" %}}), for example with [Docker](https://github.com/ElementumOrg/elementum-docker).
